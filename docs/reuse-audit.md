本机 Konsole 启动项后来改为直接运行 `/usr/bin/konsole --separate -stylesheet …/PanelGlass.qss`，并移除了 `konsole-glass` 启动器；这会绕过本仓库的菜单运行时。为保留现有设置，此次审计未修改当前桌面的启动入口。完整恢复流程使用仓库的 `konsole-glass` 启动器，覆盖主窗口样式和菜单效果。

本次是在当前系统上使用干净源码和临时 HOME 验证，没有重装系统或在空白虚拟机中安装全部依赖。面板布局进行了模拟和只读对照，未在当前桌面重建。截图授权声明已检查；临时 HOME 验证没有替换当前会话的授权数据库或重新调用 CaptureScreen。

仓库保存主题定义，不保存壁纸、个人文件、NetFloat 的位置/网卡设置、现有面板完整转储或开机自启。顶部面板及底部 Dock 的定义在 `layout/panels.js`，注销并重新登录后显式传入 `--panels` 才重建；该选项会替换现有面板。

需要已安装的相应 KDE/Qt 应用及开发依赖。其他 KDE/Qt 版本须重新构建；补丁不兼容时迁移后再恢复，不能承诺未来所有版本均可直接使用。私有仓库克隆仍需 GitHub 认证，认证信息不保存在仓库中。
